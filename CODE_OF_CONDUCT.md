# Code of Conduct

## Our Pledge

We are committed to making this project a welcoming, respectful, and inclusive space for everyone who wants to use or contribute to the Simple Interest Calculator.

## Expected Behavior

Contributors are expected to:

* Be respectful and considerate toward others.
* Communicate clearly and constructively.
* Accept constructive feedback gracefully.
* Focus on improving the project and helping other contributors.
* Respect people with different backgrounds, experiences, and skill levels.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, discrimination, or personal attacks.
* Offensive or inappropriate comments.
* Trolling, insulting, or deliberately disrupting discussions.
* Sharing private or sensitive information without permission.
* Any other behavior that creates an unsafe or unwelcoming environment.

## Contributions

When contributing to this repository, please:

* Follow the project's contribution guidelines.
* Submit useful and relevant changes.
* Test your changes before submitting a pull request.
* Clearly describe bugs, improvements, or new features.
* Respect the decisions of project maintainers.

## Reporting Issues

If you experience or observe unacceptable behavior, please report it to the repository maintainer through the appropriate GitHub contact or issue-reporting channel.

All reports will be reviewed and handled as appropriately as possible.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions, commits, and other project-related interactions.

## Enforcement

Project maintainers may take appropriate action in response to violations of this Code of Conduct, including removing inappropriate content, restricting participation, or taking other reasonable measures.

## Acknowledgment

By participating in this project, you agree to follow this Code of Conduct and help maintain a respectful and collaborative community.
